# HANDY PALS assets

Generated specifically for EXP-045 using the built-in Imagegen tool on 2026-10-03.
The character atlas is truly transparent; its alpha is retained in both WebP sprites.
The cover is a separate Imagegen illustration. Gameplay uses the generated sprites
with code-driven squash, stretch, stepping, jumps, turns, sparkle and duo interactions.

| Asset | Dimensions | Use |
| --- | --- | --- |
| bear-v1.webp | 458 × 576 RGBA | Bear sprite and selector |
| bunny-v1.webp | 352 × 576 RGBA | Bunny sprite and selector |
| cover-v1.webp | 720 × 1279 | Illustrated entrance |
| ../../../public/previews/handy-pals.webp | 720 × 1279 | Discovery preview (same cover) |

Exact prompts, source locations, normalization and the music license/source/checksums
are recorded in [the asset manifest](../../../docs/handy-pals-assets.json).

Effects are original short oscillator sounds, without sampled third-party audio.
