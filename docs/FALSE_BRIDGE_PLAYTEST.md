2026-10-03 / Prototype v0.1. **未実施：0 / 5セッション。**
ブラウザーの自動操作・合成映像はこの表のセッション数に含めない。

## 準備

- 実機iPhone Safari / Android Chrome。HTTPSで `/#/game/outcam-false-bridge` を開く。
- 「カメラを使ってはじめる」でアウトカメラを許可。デスクトップ等に背面カメラがなければデモを使えるが、カメラの体感評価には数えない。
- 各問の開始時、ガイドから物を外し「背景をセット」。1秒静止後、身近な形を探して重ね、LOCK。
- 最初は使う物を指定しない。物の位置・角度・距離に加え、スマホを動かせることをプレイヤーが発見するか観察。
- 明るい無地の背景、複雑な背景、暗所を含める。カメラを大きく動かした後は自己確認または「背景を撮り直す」。
- 5問目は橋を固定後に物を外し、柱用の背景をセット。先に固定した橋が残ることを確認。

## 実機の動作確認

- 360×800相当でLOCK・背景セット・自己確認の各操作に到達できる。
- 前後の向き、左右の鏡像、物理的に丸い物が画面でも丸いことを確認する。
- 縦横回転・近づく・離れる・傾ける後も、表示ガイドと固定した切り抜きがずれない。
- 2つ目の物を探している間、1つ目の切り抜きが消えない。
- カメラ拒否→再試行／デモ、バックグラウンド→明示的な復帰と再撮影を試す。
- 中断、結果、フィードへ戻る操作でカメラ使用が止まる。
- 本人が合っていると思ったLOCKを自己確認で受け入れられる。
