## 共通ルール

`src/camera/rules.js` は描画・入力に依存しない状態更新。`stages.js` の足場データでルールとパラメータを指定する。

| Rule | 初期値 | 動作 |
| --- | --- | --- |
| VISIBLE | — | 視認中だけ衝突可能 |
| FOCUS_HOLD | 500ms / grace 180ms | 連続視認で実体化。短い境界揺れは保持し、猶予を超えるとリセット |
| AFTERIMAGE | 1500ms | 視野外でも衝突を維持し、アルファで残り時間を表現 |
| OVEREXPOSE | 1200ms / recovery 700ms | 長時間視認で白化・点滅・消失。視線を外して700msで回復 |
| LINKED | requiredVisible 2 | グループの視認アンカー数で橋を実体化 |

新ルールの視認は足場上面中央のアンカーと7%のマージンで判断。既存001〜005は10%の面判定と240msの猶予を維持する。
LINKEDは独立した観測アンカーでも、同グループの足場同士でも指定可能。
OVEREXPOSEは一度視認したあと、視野外で回復する間も未消失なら衝突を維持する。この解釈で「乗ったあと視線を外す」が成立する。
010のAは `FOCUS_HOLD` に `memoryMs:1500` を指定し、保持→記憶を合成する。
将来の6ルールは識別子のみ予約し、未実装ルールは衝突を有効にしない。

006〜009の短いJA/EN学習テキストは歩行開始後800msで消える。010クリアで「見ることで 世界は変わる」。
001〜010の失敗は原因足場に視野を戻して500ms静止し、同面を再開。短い準備600msを含め約1.1秒。
死亡原因・対象足場・時刻を `attempts` に記録。最終結果にも含め、従来のローカル結果保存に乗せる。
