## Boundaries and contract

`Camera Input → MotionNormalizer → TrackingRecovery → MotionSmoother → Driver`.
AvatarLayer owns no camera, model or RAF. The owning controller supplies results
at inference cadence and calls `update()` from its existing display loop.
Three and three-vrm are loaded only when that renderer is explicitly selected.
The feed and games that do not select AVATAR do not import the layer or create it.

`src/avatar/motion/MotionFrame.js` documents the contract:

- timestamp: monotonic **milliseconds**, using the inference/display clock.
- driver dt: **seconds**.
- head: normalized ±1 = ±60°; joints ±1 = ±180°. v0.1 arms use camera-plane Z
  rotations. X/Y remain neutral; no full-body IK, depth reconstruction or fingers.
- coordinates: camera X right / Y up / Z toward camera, **before mirroring**;
  handedness is anatomical. A renderer applies mirror once.
- wrist positions come from pose when available. `source: 'pose'` has no finger
  estimate; `source: 'hand'` adds experimental open/pinch/direction.
- tracking booleans describe current fresh observations. Holding the previous
  pose during a short loss does not fabricate tracking success.
- multiple faces, malformed data and confidence below .5 do not drive the rig.
  Head matrices and blendshapes are preferred; existing landmark-only inputs
  can provide coarse head roll/yaw, mouth and blink. Landmark-only pitch is neutral.
- values never leave the normalized frame as raw MediaPipe landmarks. Debug RAW
  reports input counts, avoiding retention of full face/hand geometry.

```js
// Inside an opted-in game; do not load this for games without a puppet.
const [{ AvatarLayer }, { BIRD }] = await Promise.all([
  import('../avatar/AvatarLayer.js'), import('../avatar/profiles/index.js'),
]);
const puppet = new AvatarLayer({ preset: 'GAME_NORMAL' });
await puppet.load({ host, driver: 'mascot', profile: BIRD, cameraMode: 'MIRROR' });

// Reuse the results already produced by Camera Input Layer.
puppet.ingest({ face: faceResult, pose: poseResult, hands: handResult,
  aspect: video.videoWidth / video.videoHeight }, inferenceTimestampMs);
// Sample after inference; RAF's start timestamp may precede its result.
puppet.update(performance.now(), deltaSeconds);

// A game controls visibility and cleans up on result/retry/exit.
puppet.setVisible(true);
puppet.dispose();
```

## Reliability and performance

Face, body and each wrist recover independently: hold through 200ms, ease from
200–700ms, then idle. A new observation blends from the current pose over 180ms.
An observation older than 180ms is stale even if its original tracking was true.
Body motion inferred from face XY also follows the loss policy. Time-based
exponential smoothing follows at display cadence between recognition samples;
joint angles take the short arc, while positions interpolate linearly.

The dedicated PuppetInput inherits the shared BodyInput lifecycle and opens
one front stream, without a microphone. MEDIUM is the default: lite pose and
face at 15–20Hz, no hand model. HIGH can add hands; LOW keeps pose only. Sustained
display FPS below 26 lowers quality, with a six-second cooldown. Downgrades
close unused models without reopening the camera. At LOW the playground selects
the simple puppet. Pause/background suspends inference and puppet clocks.

Primitive geometry is procedural and has no model download. The project-authored
VRM 1.0 fixture is **7,269 bytes**, generated by `scripts/generate-puppet-vrm.js`.
It has a humanoid hierarchy, mouth and independent blink morphs, and no textures.
`@pixiv/three-vrm` is pinned to 3.5.5; loading uses VRMLoaderPlugin and normalized
bones. Built-in LookAt can receive head-derived gaze when the model supports it.
An authored model URL can be supplied by a game; upload/UI/model sharing is absent.

Loading, swapping drivers and exiting use generation guards. Late models never
attach after exit; pending/current WebGL layers, geometry/materials, Canvas2D
surfaces and camera models are released. WebGL failure switches to the 2D driver.

## Creator privacy

AVATAR returns before any camera draw. The shared `drawFaceMode()` and
`CreatorMode({ avatar: () => puppet.canvas })` support a transparent avatar canvas
over the existing background/game FX. Missing tracking, loading and WebGL failure
never substitute camera imagery. BODY WINGS records its already composed sky,
bird and wings with no second camera layer. The puppet test uses the same shared
recorder and exporter. If a player switches face modes mid-clip, the result shows
every selected mode, so earlier ORIGINAL frames are not labeled AVATAR-only.
Frames stay in bounded memory, and exit/retry discards them; no image or biometric
data is persisted or uploaded. Video saving is an explicit player action.
