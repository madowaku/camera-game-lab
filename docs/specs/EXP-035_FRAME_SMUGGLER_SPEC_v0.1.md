# EXP-035 FRAME SMUGGLER / フレーム密輸団

Prototype v0.1 · 2026-10-03

## 核となる問い

「ちゃんと撮る」と「わざと撮らない」を交互に要求すると、撮影者と運び屋が自然に声を掛け合うか。点数より、撮影者の参加感・会話・役割交代して再挑戦したい気持ちを重視する。

## 1本の30秒Survival

- CAMERA: スマホを持つ。SMUGGLER: 片手を映す。前後カメラを開始前に選択する。
- READY: 手のひら中央（wrist / index MCP / pinky MCPの平均）に宝石。内側で400ms安定したらSTART可能。
- COUNTDOWN: 2秒。手が内側に映っている間だけ進む。ラウンド30秒には含めない。
- KEEP: 安全マージン内に宝石がある間、毎秒10点。画面中央への追加点はない。
- WARNING: 1.5秒。`INSPECTION IN 2…1`。警告中の通常加点は停止。
- HIDE: 2.5秒。宝石を画面外へ出し、検問終了まで隠す。終了時に連続250ms以上のOUTSIDEなら `CLEAR! +100`。それ以外は `CAUGHT!`。
- RETURN: `BACK!`。安全マージン内に戻ったら `SAFE` と加点を再開。再入場しなければ次の検問では得点できない。
- RESULT: SCORE / INSPECTIONS CLEARED / BEST HIDE TIME / CAUGHTの4項目。成功しなかった場合のBESTは「—」。SWAP ROLESでP1/P2の担当表示を反転してREADYへ戻る。

ユーザー仕様の「30秒・4〜6回・警告1.5〜2秒・検問2.5秒・通常2〜5秒」を両立させるため、MVPは検問4回で固定する。5つの通常区間に合計14秒をランダム配分し、警告6秒＋検問10秒と合わせて正確に30秒。RETURNで戻るのが遅くても次の警告は予定どおりに開始する。開始カウントダウン、一時停止、映像停止は30秒に含まない。

## フレーム判定

表示上の `object-fit: cover` の切り抜きと前カメラの左右反転を手座標にも適用する。元映像全体ではなく、プレイヤーが見ているフレームを判定する。

| 状態 | 判定と挙動 |
| --- | --- |
| INSIDE | 上下左右8%の安全マージン内。KEEPで加点、READY・RETURNの復帰に使う |
| EDGE | 安全マージンから画面外2%までの境界帯。加点・HIDE成功なし |
| OUTSIDE | 追跡点が表示領域外へ2%以上移動。または、画面端へ向かう移動の直後に手が消え、その後180ms以上新しい「手なし」推論が届く |
| LOST | 中央で消えるなど、外へ出た証拠がない認識ロスト。`LOST CARGO!`、加点なし。HIDE成功にしない |
| STALE | 新しい推論が500ms届かない。映像停止として時計を止め、更新復帰後に明示的な再開を求める |

OUTSIDEはMVPの推定であり、画面外にある物理的な手の位置を保証しない。端での遮蔽・非常に速い移動は誤判定し得る。実機プレイテストで「端を通ったのにLOSTになった」「隠していないのにCLEARになった」を記録し、しきい値を調整する。手は1つだけ提示する。複数人・複数の手の同一性追跡は対象外。

## 操作・終了・保存

- カメラの起動は明示操作。前後を切り替える際は旧ストリームと認識モデルを終了。音声は取得しない。
- インカメラは鏡像、アウトカメラは非反転。存在しないアウトカメラを勝手にインカメラで代替しない。エラー画面で選び直せる。
- カメラなしの練習はドラッグ・矢印キー・画面外／中央ボタン。結果・共有・記録には練習と明示し、人による実機評価に含めない。
- 一時停止、背景化、映像停止で時計を止める。結果・退出・遅れて返ったカメラ許可でもストリームを解放する。
- 最後の50戦を端末内に保存。日時・入力源・カメラ向き・担当・点数・検問結果・認識ロスト回数。カメラ画像・動画・音声は保存しない。
- カメラ戦の結果から6項目を「はい／いいえ／未確認」で記録できる。JSONエクスポート対応。保存できないブラウザーではそのセッション内だけ保持し、その旨を表示する。

## Human Playtest Gate

実際の二人で5戦行い、次を観察する。

1. 説明10秒以内で始められるか。
2. KEEP / HIDEを間違えないか。
3. 撮影者もゲームに参加している感覚があるか。
4. 自然な会話が起きるか。
5. 検問で笑いや慌てが発生するか。
6. 役割交代でもう一度遊びたいか。

3 / 4 / 6を中心に人が判断する。観察記録が5件になっても自動的に成功と判定しない。ブラウザー自動操作・合成ランドマークでこのゲートを代替しない。

## 次の候補（MVPには含まない）

DOUBLE CARGO / FACE CONTRABAND / PARTIAL INSPECTION / MOVING CHECKPOINT / DON'T HIDE THE SMUGGLER。最初の5戦で体感を確認してから検討する。
