# EXP-019 NOTE BLASTER 仕様書 v0.1

## 1. 概要

**NOTE BLASTER** は、五線譜上を攻めてくる敵に対し、プレイヤーが声で音階を発声して撃退するインカメラ・ボイスシューティングゲーム。

プレイヤーの顔が画面下部または左側に表示され、発声した音程に応じて、**口元から対応する高さの音符弾が発射される。**

敵は五線譜上を進軍してくる。

敵と同じ高さの音を出せば命中。

> 歌う高さ = 狙う高さ

という直感的な操作をゲームの中心にする。

---

# 2. コアコンセプト

## 一言で

**声で五線譜を撃つ。**

## ジャンル

- ボイスシューティング
- 音程ゲーム
- カジュアル音ゲー
- インカメラゲーム

## 特徴

通常の音ゲーは、

「表示された音に合わせて操作する」

ものが多い。

NOTE BLASTERでは、

**自分の声そのものが弾になる。**

音程認識が照準操作を兼ねる。

---

# 3. 基本画面

画面中央に横方向の五線譜を表示する。

```text
────────────────────────
        👾
────────────────────────
              👾
────────────────────────
    👾
────────────────────────
────────────────────────

🙂 ♪──────────────→
```

敵は画面右側から左側へ進軍。

プレイヤーは画面左側。

インカメラ映像から顔と口位置を取得し、

**口元から音符が飛び出す。**

---

# 4. 基本操作

操作には主に以下を使用する。

- マイク
- インカメラ

タップ操作はゲーム開始・停止など最低限のみ。

---

# 5. 発声による攻撃

プレイヤーが声を出す。

例：

```text
ドーーーー
```

音程を解析。

認識した音程に対応する五線譜位置から、

```text
♪
```

が発射される。

音符は水平に飛ぶ。

---

# 6. 音程判定

音程は連続した周波数として取得する。

例：

```text
261Hz
```

↓

```text
C4
```

↓

```text
ド
```

として扱う。

初期版では、

```text
ド
レ
ミ
ファ
ソ
```

程度から開始する。

最終的には、

```text
ド レ ミ ファ ソ ラ シ ド
```

まで拡張可能。

---

# 7. キャリブレーション

絶対音感を要求しない。

ゲーム開始前にプレイヤーの声域を簡単に測定する。

例：

```text
あなたの出しやすい声で
「ドー」と歌ってください
```

その音を基準音として記録。

以降は相対的な音程差で、

```text
ド
レ
ミ
ファ
ソ
```

を判定する。

---

# 8. 初心者補正

厳密な音程一致を要求しない。

各音には判定幅を持たせる。

例：

```text
PERFECT
GOOD
MISS
```

PERFECT  
中心音程付近。

GOOD  
多少ズレている。

MISS  
別の音階。

---

# 9. 音符弾

発声すると口から音符が生成される。

例：

```text

```

声を伸ばすと連射。

```text
ドーーーー
```

↓

```text
♪ ♪ ♪ ♪ ♪ ♪
```

短く歌うと単発。

```text
ド！
```

↓

```text
♪
```

同じ音を連続して当てる必要がある。

```text

```


## CHORD ENEMY

複数レーンを占有する敵。

例：

```text

ミ
ソ
```

の3か所。

すべて破壊すると撃破。

---

## SCALE ENEMY

指定順に攻撃する。

例：

```text

```

---

## REST ENEMY

特殊敵。

**声を出してはいけない。**

沈黙すると撃破できる。

```text

歌う
黙る
歌う
```

というリズム変化を作る。


```text

```

3回突破されるとGAME OVER。

```text

```


音符の演出を派手にする。

# 38. EXP-019の目的

NOTE BLASTERで検証するものは、

音程認識技術そのものではない。

検証したいのは、

> **声の高さを空間操作として使うゲームが面白いか**

という一点。

そのため、

EXP-019では機能追加よりも、

```text
声を上げる
↓
弾が上がる

声を下げる
↓
弾が下がる
```

という身体感覚を最優先する。
