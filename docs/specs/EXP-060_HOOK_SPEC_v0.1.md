# EXP-060 HOOK!
## Camera Fishing Game
**Status:** Prototype Spec v0.1  
**Mode:** SOLO / Front Camera  
**Play Time:** 約30秒  
**Orientation:** Portrait 9:16  
**Input:** Hand / Arm movement  
**Target:** Mobile Web / camera-game-lab

---

## 1. CONCEPT

**魚が食いついたら、身体ごと引け。**

プレイヤー自身が釣り人になるインカメラ釣りゲーム。

細かなリール操作は使わない。

- 投げる
- 合わせる
- 魚と逆方向へ引く

この3動作だけで巨大魚との格闘を成立させる。

ゲーム画面だけでなく、

**「魚に振り回されているプレイヤー本人」**

まで含めて面白いことを目標とする。

---

# 2. CORE LOOP

### ① CAST

画面下部に水面。

プレイヤーが片手を前方へシュッと振る。

```
   🙂  ／
      ／  🎣
~~~~~~~~~~~~~~
```

大きな腕移動を検出すると、

**CAST!**

ルアーが水面へ飛んでいく。

入力が取れなかった場合は画面タップでもキャスト可能。

---

### ② WAIT

水中に魚影が見える。

```
~~~~~~~~~~~~~~
       ● lure

   🐟 →
```

魚によって近づき方が違う。

小魚はすぐ食いつく。

大型魚はルアーの周りを何度か回る。

ときどき偽物のアタリも発生。

---

### ③ BITE

```
    !
    |
~~~~~~~~~~~~~~
      💥
```

**HIT!**

スマホ振動。

水しぶき。

SE。

画面が一瞬ズーム。

ここでプレイヤーは

**手を上へ引き上げる。**

---

### ④ HOOK

一定時間内に手を上げられれば、

**HOOK!!**

失敗すると、

**MISS...**

魚は逃げる。

判定は厳密な釣り動作ではなく、

> 手のY座標が一定量上方向へ移動

という単純で安定した入力を優先する。

---

# 3. FIGHT

ここがゲーム本体。

魚が左右へ暴れる。

```
🐟 ←←←←────🎣
```

魚が右へ逃げた場合、

プレイヤーは

**左へ手を引く。**

```
← PULL!
```

魚が左なら右。

---

## TENSION

画面中央にテンションゲージ。

```
LOOSE       GOOD       BREAK
|-----------████---------|
             ▲
```

プレイヤーの操作でテンションが変化する。

逆方向へ適度に引く

→ GOOD

何もしない

→ LOOSE

強く引きすぎる

→ BREAK

---

## LOOSE

テンション不足。

```
スポン！
```

魚が逃げる。

---

## BREAK

テンション過多。

```
ブチッ！
```

糸が切れる。

---

## GOOD

GOODゾーンを維持すると

**LANDINGゲージ**

が溜まる。

満タンになるとフィニッシュへ。

---

# 4. FISH BEHAVIOR

魚は単純な左右往復ではなく、

**予兆 → ダッシュ → 疲労**

の3状態を持つ。

予兆では魚が身体を振る。

```
🐟 〰
```

0.3〜0.5秒後にダッシュ。

プレイヤーは魚を見て反応できる。

つまりゲーム性は、

**反射神経 + 観察**

になる。

---

# 5. LANDING

LANDINGゲージが満タンになると、

魚が水面へ急上昇。

```
        🐟
       ／
~~~~~~💥~~~~~~
```

そして画面手前へ、

# バシャアアアン!!

Three.js演出で魚がカメラ方向へ飛び出す。

一瞬画面いっぱいになる。

スローモーション。

水滴。

カメラシェイク。

# 13. INPUT RELIABILITY

HOOK!では認識精度を最優先する。

細かい指形状は使わない。

MediaPipe Hand Landmarkerで

- 手の中心位置
- 移動量
- 移動方向
- 移動速度

だけを見る。

主入力は、

**大きなX/Y移動。**

FINGER GUNやSOFT SERVEより認識難易度をかなり下げる。

手を見失った場合、

ゲームは一時的にテンション変化を停止。

即座に敗北させない。

# 20. SUCCESS GATE

v0.1成功条件。

初見プレイヤーが説明なしでも、

**魚が右へ行ったら左へ引く**

ことを理解できる。

5ゲーム中4ゲーム以上で入力が成立。

HOOK入力成功率 90%以上。

認識失敗による理不尽な敗北がほぼない。

そして最重要条件：

**魚がHITした瞬間、プレイヤーが反射的に身体を動かす。**

ここが成立すればEXP成功。
