# EXP-059 HUMAN FISH / 人面魚生活 v0.1

実装日: 2026-10-06。ユーザーのこのチャットの企画を基にした実装仕様。

> 美しい水槽の中で、人面魚として生き延びる。欲張るほど息が苦しくなる。

## 遊び

通常ラウンドは45秒。開始時の酸素は100%。顔の左右・上下移動で泳ぎ、
口を閉じてから開くと水中では近くのエサを一つ食べ、水面では息継ぎする。
水面へ着いただけでは酸素は回復しない。息継ぎは100%まで一気に回復し、
水面の波、水滴、体の震え、PUHAAAA!!と音で知らせる。

| エサ | 場所 / 解禁 | 点 | 食べた時の追加酸素消費 |
| --- | --- | ---: | ---: |
| 小さなエサ | 上層、最初から | 1 | 0.4 |
| エビ | 中層、最初から | 3 | 1.5 |
| 真珠 | 底、20秒 | 10 | 4 |
| 巨大真珠 | 底、24 / 34秒 | 20 | 8 |
| 黄金のエサ | 底、30 / 39秒 | 15 | 6 |

巨大真珠・黄金のエサを食べると、横に追加のエビが出る。
30秒から通常エサの間隔が3秒から1.6秒へ短くなり、酸素消費も16%増す。
酸素の基本消費は毎秒4.8 + 水深比率 × 2.8。底ほど苦しくなる。
エサは最大14個。小さなエサは14秒、その他は24秒で消える。

38秒から猫の手。現在の横位置付近に1秒の予告ゾーンを出し、
0.7秒の攻撃を行う。2.7秒間隔で計3回、最後の攻撃も45秒以内。
横によけて別の場所で呼吸できる。
叩かれると酸素−12、深さ42%の位置へ押し戻され、0.4秒動けなくなる。
一回の攻撃は一回だけ当たる。

酸素が少なくなると顔の眉と口が苦しそうになる。5%以下では
軽いレンズ変形と周辺暗化、BGM/SEのこもる音。0%ではゆっくり浮上して
「ぷかー……」。死亡アニメーションの1.8秒は生存時間に含めない。

## 入力と復帰

既存のMediaPipe FaceLandmarkerとNoteEaterInputを再利用。顔一人、
口の縦横比、実カメラの縦横比を使う。眼球・視線・首の角度は操作に使わない。
中央で約0.6〜0.8秒静止して中立点を取り、少しの平行移動を水槽全体へ拡大する。
横は鏡像。口は45ms / 65msのヒステリシス判定を経て、閉→開の一回だけ反応。
開けっぱなしで連続採食・呼吸をしない。復帰直後も口を閉じる必要がある。

入力が200ms古い / 顔を見失った場合はその場で浮遊。
0.5秒以上続くと酸素とゲーム時間を止める。顔が戻ると自動再開。
カメラが停止・拒否された場合は再接続またはタップ練習へ進める。
カメラなし練習は水槽タップ・ドラッグ、矢印 / WASDで泳ぎ、ボタン / Spaceで口。
Pまたは画面ボタンで一時停止。バックグラウンド時にも酸素・時間を停止。

## 人生記録

終了時はHUMAN FISH REPORT。「人面魚として38.4秒 生きました」の文面。
生存時間、食べたエサ、呼吸回数、最深潜水、酸素10%以下での呼吸、猫の回数を表示。
称号は猫の友達、欲張り人面魚、エビ絶対食う魚、酸素管理士、深海人面魚、
水面の住人、駆け出し人面魚。行動記録で決まり、スコアだけでは決まらない。
RETRY / NEXT / SHARE。練習記録は共有文にも練習と明記。

## 自分が住人になる

通常PLAYでもEFFECTを既定に、自分の顔を魚の頭に合成。
CREATORはEFFECT / ORIGINAL / HIDE。EFFECTは鱗と少し飛び出した魚の目、
ORIGINALは自分の顔、HIDEは生成した人面魚の顔。
PHOTOで「今日の人面魚」のPNGを保存。終了時にも最後の水槽写真を保存できる。

CREATORは既存のDirectorRecorder / AutoDirector / ClipComposer / Exportを使い、
実際の息継ぎをHEROとして7秒の映像を選ぶ。直前の欲張り・浮上と直後の反応を
含める。終盤の息継ぎなどで反応区間が短い場合は、人生記録の終了カードを
延ばして7秒にする。顔・水槽・残り時間・酸素・点数が合成済みのフレームだけ保持。
12秒のローリングバッファと重要区間、24MiB上限、負荷時は解像度/頻度を下げる。
動画は音声なしで端末内に生成し、保存操作時にのみダウンロード。
実プレイにない「酸素1%→猫パンチ」をリプレイへ捏造しない。

## 構成

`src/humanFish/core.js`が純粋なルール、`signals.js`が顔の操作、
`scene.js`が既存PhaserRuntimeを使う描画、`view.js`がDOMとライフサイクルを担当。
顔は小さなCanvasTexture。水槽はImagegenの静止画に魚・泡・エサ・猫を重ねる。
再挑戦は同じPhaser.Gameを再利用し、Feed退出時に破棄する。
背景・キャラはWebP、BGMはゲーム開始時に遅延ロードするインラインMP3。
音楽の単体ダウンロードや鑑賞機能は設けない。

実装上の提案として、猫の予告と長い追跡ロスト中の酸素停止を追加した。
新しい外部サービスは不要。費用のあるプラグインの追加はしていない。
物理カメラの追跡感度、スマホのGPU・負荷、実際の「あと1個」の気持ちよさは
人による実機プレイでの調整対象。
