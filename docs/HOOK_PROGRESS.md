# EXP-060 HOOK! v0.1

実装・検証日：2026-10-06〜07。入口は `#/game/solo-hook`、短縮入口は
`#hook`。Feed / Exploreから起動できる。

## 遊べる範囲

片手を振ってCAST、ウキが沈んだHIT!!で上へHOOK、魚と逆方向へ引いて
GOODテンションを保つ。予兆450ms → ダッシュ → 疲労 → 方向変更を見て
対応する30秒の釣りゲーム。AJI / TAI / TUNA / BOOT / HUMAN FISHの5種、
PERFECT HOOK、サイズ・テンション・速さの加点、3連続成功のFEVER
（+5秒、8秒間レア率とBGM速度UP）、釣果内訳、リトライ、結果共有まで実装。
人面魚には「釣るなよ。」とRELEASEを表示し、「同業者」の解除を端末に記録する。

カメラなし練習は同じルールを使用する。タップ / Spaceで投げる、上スワイプ /
↑ / HOOKボタンで合わせる、横ドラッグ / 左右ボタン長押し / ← → / A Dで引く。
Shiftを併用すると強く引きすぎる状態も試せる。Pと画面ボタンで一時停止できる。
JA / EN、独立したSE切替、共通BGM切替、Reduced Motionにも対応する。

## 仕様からの具体化

- 最初の釣り上げ成功までアジに固定し、最初のHOOK猶予を1.8秒に広げた。
  以後は1.35秒。開始前は3つの動作をイラストと短文で説明する。
- 一人用のHand Landmarkerを使い、手の枠を固定する。二人用の位置による
  手の割り当てでは、大きいCAST動作を別人の手として扱う問題があったため。
- 手を見失った直後から魚・テンション・残り時間を停止する。450ms後に
  復帰案内を表示し、200ms安定した入力で復帰する。古い移動履歴を捨て、
  復帰時の手の位置でCASTやHOOKが勝手に発生しないようにした。
- 一瞬のテンション逸脱は即敗北にしない。端の危険域が続いた場合に
  糸切れ / 逃走となる。緑の中でも逆方向への適度な入力を必要とする。
- Imagegenの魚をPhaserとThreeの両方で共有する。釣り上げ時は曲面メッシュを
  カメラ方向へ飛ばし、絵柄を保ちながら画面いっぱいに見せる。Threeが利用
  できない場合はPhaserのジャンプへ戻る。
- 釣り上げた最大サイズの魚の記念写真を端末内で作る。結果の保存ボタンを
  押した場合だけPNGをダウンロードする。カメラ映像・写真はアップロードしない。

CREATOR / 7秒動画、TREASURE / UFO、DUO、図鑑、ルアー選択などは仕様の
MVP後の候補。今回の30秒モードでは魚種は抽選で決まり、狙う魚の選択操作はない。

## 実装の責務

`src/hook/core.js`が全ルールと時間を所有する。`signals.js`と`input.js`は
片手の認識・ミラー変換・大きな移動の判定、`view.js`はカメラ・操作・
画面・結果への接続を担当する。Phaserは既存の共通Runtime / Scene / FXを使う。
Threeは共通のVisualSessionを使い、ゲームの判定や第二の時間進行を持たない。
カメラ背景はDOM videoで表示し、写真の生成時だけ完成画像を端末内で合成する。

結果でカメラ・SE・Threeを解放し、Phaserのループを停止する。リトライは
Phaser.Gameを再利用し、退出時にはRuntimeも破棄する。

## 素材

魚5種とカバーは組み込みImagegenで生成し、透過を保ってWebPに変換した。
生成プロンプトは[記録](hook-image-prompts.txt)、元画像・加工・SHA-256・
ライセンスは[素材台帳](hook-assets.json)に保存している。

BGMは既存の正規ダウンロード済みOpenTracks
[「ぷかぷか」 / ゆうり](https://opentracks.com/bgm/detail/11821)を再利用。
[サイトの音源ライセンス](https://opentracks.com/help/articles/license/)と
[作者条件](https://opentracks.com/creator/detail/204#terms-of-use)を確認し、
商用ゲームBGMとして使用する。ゲーム中だけ再生し、単独の音楽ダウンロードや
音源を書き出す機能は提供しない。FEVERは再生速度1.16倍。

竿の振りと衝撃のアクセントはAssetsSharedにあるKenney
[RPG Audio](https://kenney.nl/assets/rpg-audio) /
[Impact Sounds](https://kenney.nl/assets/impact-sounds)のCC0素材。
残りの水しぶき・成功・糸切れの音はWeb Audioで合成する。

## 検証と残る確認

コミット対象だけを抜き出した状態で `npm test`：553件成功。HOOK専用の10件は釣りの一巡、偽アタリ、HOOKの
時間切れ、糸切れと逃走の継続判定、追跡停止、FEVER、RELEASE、30秒終了、
魚の予兆と方向変更、手の復帰と一人枠の回帰を検査する。
Production buildも成功。

ブラウザ検証スクリプト：

- `scripts/qa/hook.js`（32項目）：390 / 1440 / 320pxの入口、全画像、練習から実操作で
  3匹釣り上げ、FEVER、加点、写真、JA / EN、SE / BGM切替、結果、
  リトライ、退出時のリソース解放。
- `scripts/qa/hook-camera.js`（11項目）：認識器と映像入力を置き換えたカメラ経路。
  権限拒否、手のCAST / HOOK / PULL、追跡ロストと復帰、実加点と写真、
  退出時の映像トラック解放。
- `scripts/qa/hook-production.js`（14項目）：ビルド済みゲームを通常UIだけで操作。
  上ドラッグ、左右ボタン長押し、釣り上げ、結果とローカルPNG保存。
- `scripts/qa/hook-edges.js`（13項目）：Threeのコンテキストロスト後もPhaserで
  釣り上げ、人面魚のRELEASEと実績の保存、長靴の表示サイズ、実行中の
  Reduced Motion変更、フォーカスを外した時の停止。

以上70項目が成功し、ブラウザの未処理例外は0件。

スクリーンショットとログは `output/` に保存する。これらの検査は
実際の人の手によるMediaPipe認識、スマホのGPU負荷、初見の楽しさを
測ったものではない。仕様の成功条件は[実機プレイ確認表](HOOK_PLAYTEST.md)で
別に判定する。

次の改善は魚種を増やす前に、スマホで5ラウンド遊び、引く距離・HOOK閾値・
大型魚に必要な時間を調整するのがよい。大物を選んで狙う楽しさが欲しい場合は、
その後にルアー選択を小さく追加する。
