# EXP-048 POSE WALL
## 上半身ポーズ合わせ壁抜けゲーム
**Detail Design v0.1**

---

## 1. ゲームコンセプト

カメラに映ったプレイヤーの前へ、身体の形にくり抜かれた壁が迫ってくる。

プレイヤーは壁の穴と同じポーズを取り、

**スポッ！**

と壁を抜ける。

ルール説明を読まなくても、

**「この形になればいい」**

と画面だけで理解できるゲームを目指す。

---

## 2. EXP-048の核

POSE WALLで最も重要なのは、ポーズ認識そのものではない。

重要なのは次の3点。

### 2.1 一目で遊び方がわかる

壁の穴を見れば、何をすればいいか分かる。

文字による説明を極力不要にする。

### 2.2 成功した瞬間が気持ちいい

壁が身体ギリギリを通り抜け、

- スポッ
- シュパッ
- キラッ

という感覚を作る。

### 2.3 失敗しても面白い

失敗時も即ゲームオーバーにはしない。

- 壁にぶつかる
- 穴がグニャッと変形する
- 壁が砕ける
- プレイヤーが「むぎゅっ」と押される

など、動画として面白いリアクションを優先する。

# 3. プレイ環境

## 基本姿勢

スマートフォンを縦向き。

プレイヤーとの距離は、

**通常のインカメラ撮影距離から少し離れる程度。**

全身は必要ない。

画面内に必要なのは、

- 頭
- 肩
- 肘
- 手首
- 胸上部

まで。

腰、脚、足首は認識対象外。

# 7. ポーズ判定方式

絶対座標ではなく、

**身体に対する相対方向**

で判定する。

例：

### Y POSE

```text
左肩 → 左肘 = 左上
左肘 → 左手首 = 左上

右肩 → 右肘 = 右上
右肘 → 右手首 = 右上
```

### T POSE

```text
左肩 → 左肘 = 左
左肘 → 左手首 = 左

右肩 → 右肘 = 右
右肘 → 右手首 = 右
```

これにより、

- 身長
- 腕の長さ
- カメラとの距離

による影響を減らす。

# 8. ポーズ内部表現

各腕を2本のベクトルとして扱う。

```text
肩 → 肘
肘 → 手首
```

それぞれを大まかな方向へ量子化する。

方向候補：

```text
UP
UP_LEFT
LEFT
DOWN_LEFT
DOWN

UP_RIGHT
RIGHT
DOWN_RIGHT
```

ただしMVPではさらに単純化し、

```text
UP
SIDE
DOWN
IN
```

程度でもよい。

---

# 9. ポーズ一致率

完全一致の○×判定にはしない。

各部位ごとに点数を出す。

例：

```text
左上腕     95
左前腕     88
右上腕     91
右前腕     82
頭位置     100
----------------
POSE SCORE 91
```

最終スコアを0〜100へ正規化。

# 11. ポーズ保持

一瞬正しい姿勢になっただけでは判定しない。

**250〜400ms**

程度の平均姿勢を使用。

これにより認識ノイズを減らす。

# 15. 壁がプレイヤーに合わせる

プレイヤーだけが壁に合わせるのではなく、

**壁側も少しプレイヤーへ合わせる。**

内部判定では個人差を吸収する。

# 34. 認識エラー対応

ゲーム中に手首が一時的に消えても即失敗にしない。

直近数フレームから補間。

例：

```text
last valid wrist
↓
150ms以内
↓
保持
```

長時間消えた場合のみ、

```text
腕を画面に入れてね
```

と小さく表示。

---

# 35. 画面外判定

プレイヤーの腕が完全に画面外へ出た場合、

ゲーム失敗ではなく、

```text
← HAND
```

のようなガイドを表示。

穴自体も画面外へ腕を要求しない設計にする。

---

# 36. 小さい画面への対応

360×800基準。

手を完全に横へ伸ばすTポーズは、

実際には画面から出やすい。

そのためポーズは、

**肩から45〜70度程度**

を基本とする。

完全な180度開脚ならぬ「開腕」は避ける。

---

```

```

「合ってるのになぜ失敗？」

# 45. EXP-048の一番大事な原則

POSE WALLは、

**ポーズ認識技術を見せるゲームではない。**

プレイヤーが、

```text
壁を見る
↓
身体を動かす
↓
スポッ！
↓
笑う
```

この約3秒を楽しむゲーム。

だから、

精度よりレスポンス。

難しさより分かりやすさ。

厳密さより気持ちよさ。

成功よりも、

**成功寸前の「むぎゅっ」まで楽しいゲーム**

にする。
