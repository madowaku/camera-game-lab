# Preview assets

`hand-beat.webp` is an original generated illustration for this sprint (2026-10-02).
Generated with the available built-in `image_gen.imagegen` tool. The user requested
imagegen2.5; the tool exposes no model selector or returned model version, so that
specific model version is **not verified**. No third-party image was used as input.

Prompt:

> Use case: stylized-concept. Asset type: actual hero preview image for HAND BEAT, a 15-second hand-gesture rhythm game in CAMERA GAME LAB, a mobile camera-native experimental arcade. Create a polished tactile 3D editorial illustration on a nearly solid deep ink olive-black background (#10120f). Central large sculptural acid-lime hand, palm facing viewer, five anatomically coherent digits, playful chunky smooth material with slightly matte finish, subtle photographic shadowing and strong shape readability. The hand is caught mid-gesture, with a few small lime rhythm blocks orbiting it and two faint offset wireframe hand silhouettes suggesting open hand -> fist -> peace. Keep it simple enough to read at 300 pixels. Diagonal dynamic composition, centered hand filling about 65% of a square image, ample clear border area. Bold contemporary art direction, experimental laboratory meets pocket arcade, elegant product render, a tiny amount of grain, controlled highlights. No people, no text, no letters, no numbers, no logo, no watermarks, no UI, no phone mockup. One square image, use the best available built-in image model.

The PNG was resized to 720×720 and encoded with ffmpeg/libwebp at quality 82.
Final size: 32,698 bytes. The original local tool output was
`01a0fcc1-dea2-74b2-9e66-ab6fed25fc0a/exec-2ee0776e-ee18-44ba-8843-fa83984d2a43.png`.
Other previews are original inline SVG/CSS in `src/platform/preview.js`.
